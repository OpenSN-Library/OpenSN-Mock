# 模拟数据说明

本文说明演示版的模拟数据层：请求怎么被接住、数据存在哪、怎么改。

## 为什么有这一层

演示版要在没有后端的情况下把页面完整展示出来：概览、三维拓扑、节点、链路、文件、数据库、终端都要能点。做法是把 axios 的请求换成本地处理，页面代码不用改，照旧调 `src/api/` 下的模块。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `src/api/client.js` | 创建 axios 实例，自定义 adapter 把请求交给模拟接口，统一处理 `{ code, msg, data }` |
| `src/api/mock/server.js` | 按路径、方法、参数分发请求，返回与真实后端相同结构的数据 |
| `src/api/mock/data.js` | 初始数据：部署机器、节点、链路、位置、节点类型、文件、数据库条目 |
| `src/api/mock/state.js` | 读写演示状态，修改后写入 localStorage |
| `src/api/mock/metrics.js` | 按时间生成资源和曲线，不存历史数据 |

一次请求的走向：

```
页面 → src/api/xxx.js → client.js（axios 实例 + adapter）
     → mock/server.js（按路径分发）→ state.js / metrics.js / data.js
     → { code: 0, msg: 'Success', data } → client.js 响应拦截器 → 页面取 res.data
```

模拟接口会等 120~300 毫秒再返回，页面的加载状态和刷新按钮才看得出来。

## 覆盖的接口

路径与真实后端一致，`/api` 前缀由 axios 的 `baseURL` 补上，下表省略。

| 模块 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 模拟运行 | GET | `/emulation/` | 运行状态与节点类型配置 |
| | POST | `/emulation/start` | 标记模拟已启动 |
| | POST | `/emulation/stop` | 标记模拟已停止 |
| | POST | `/emulation/reset` | 恢复初始演示数据 |
| | POST | `/emulation/topology` | 导入拓扑，整体替换节点、链路、位置 |
| | POST | `/emulation/update` | 合并节点类型配置 |
| 部署机器 | GET | `/node/` | 机器列表，含剩余可分配节点数 |
| | GET | `/node/:nodeIndex` | 单台机器 |
| 网络节点 | GET | `/instance/` | 全部网络节点 |
| | GET | `/instance/:nodeIndex/:instanceId` | 节点详情，含镜像、资源限额、连接关系 |
| | POST | `/instance/start` | 启动节点 |
| | POST | `/instance/stop` | 停止节点 |
| 链路 | GET | `/link/` | 链路列表 |
| | GET | `/link/:nodeIndex/:linkId` | 链路详情，含两端节点、地址、参数 |
| | DELETE | `/link/:linkId` | 删除链路 |
| 链路参数 | GET | `/link_parameter/` | 全部链路参数 |
| | GET | `/link_parameter/:nodeIndex/:linkId` | 单条链路参数 |
| 位置 | GET | `/position/all` | 全部节点经纬度与高度 |
| 资源 | GET | `/resource/last/node/:key` | 机器最新 CPU、内存；`key` 传 `all` 取全部 |
| | GET | `/resource/last/link/:key` | 链路最新收发速率、丢包、错误包 |
| | GET | `/resource/last/instance/:key` | 节点最新 CPU、内存 |
| | GET | `/resource/period/node/:key` | 机器历史曲线，附带 `period` 参数 |
| | GET | `/resource/period/instance/:key` | 节点历史曲线 |
| | GET | `/resource/period/link/:key` | 链路历史曲线 |
| 文件 | GET | `/file/list?path=` | 目录列表 |
| | GET | `/file/preview?path=` | 读文本文件内容 |
| | POST | `/file/?path=` | 上传文件，内容为 FormData，字段名 `file` |
| | DELETE | `/file/?path=` | 删除文件或整个目录 |
| 数据库 | GET | `/database/items` | 全部条目 |
| | POST | `/database/update` | 更新条目，参数 `key`、`item` |
| | POST | `/database/delete` | 删除条目，参数 `key` |
| 终端 | POST | `/webshell/instance` | 返回模拟终端页面地址 |
| | POST | `/webshell/link` | 返回模拟抓包终端页面地址 |

没有实现的路径会返回 `code: -1`，提示“演示环境没有实现这个接口”。

## 数据是怎么变的

| 操作 | 改了什么 | 页面上的效果 |
| --- | --- | --- |
| 启动 / 停止模拟 | `state.running`、`started_at` | 概览的运行状态卡片和按钮文字 |
| 启停节点 | 该节点的 `start` 字段 | 节点列表状态；节点详情资源曲线，停止后数值为 0 |
| 导入拓扑配置 | 整体替换 `instances`、`links`、`positions` | 概览统计与三维视图、节点列表、链路列表 |
| 上传节点类型配置 | 合并 `typeConfig` 里的镜像、环境变量、资源限额 | 概览的节点类型表；节点详情的资源限额与曲线量级 |
| 上传文件 | `state.files` 增加一条，同名文件会报错 | 文件管理目录树 |
| 删除文件 | `state.files` 移除该文件和它的子文件 | 文件管理目录树 |
| 修改数据库条目 | `state.database` 对应键的值 | 数据库查看页 |
| 删除数据库条目 | 从 `state.database` 移除该键 | 数据库查看页 |
| 删除链路 | `state.links` 移除一条 | 链路列表；节点详情的连接关系 |

导入拓扑要求 JSON 是对象，且 `instances` 是非空数组；`links` 可选。节点没有位置数据时，按顺序自动生成经纬度和高度，保证三维视图里能看到。节点类型配置要求是对象，`{ "类型名": { image, container_envs, resource_limit } }`。

## 保存与重置

- 每次修改后调 `saveState()`，把整个状态写进 localStorage，键名 `opensn-mock-state-v1`，值是 `{ version: 1, state }`。
- 页面第一次读数据时从 localStorage 恢复；没有、解析失败或版本号对不上，就用 `data.js` 生成的初始数据。
- 概览页的“重置模拟环境”调 `/emulation/reset`，重新生成初始数据并立即保存。
- 清理浏览器里该站点的数据等于删掉这个键，下次打开也是初始数据。
- 隐私模式或浏览器禁用本地存储时写入会失败，操作只在当前页面有效，刷新后回到初始数据。

## 资源曲线怎么来的

`metrics.js` 按当前时间往前推，现场算出曲线，不存历史：

- 时间范围有 9 档，从 `1m` 到 `24h`，每档的点数和间隔固定，默认 `10m`。
- 每条曲线用节点或链路 ID 的哈希做种子，所以同一个对象每次刷新的曲线是连续的，数字会缓慢起伏。
- 节点停止时，节点资源接口返回 0；链路禁用或参数 `connect` 为 0 时，链路资源接口返回 0。
- 资源数据与“模拟是否启动”无关，`running` 只影响概览的运行状态显示。

## 如何新增模拟接口

1. 在 `mock/server.js` 里，最后一个 `return fail(...)` 之前加分支。用 `segments`（路径按 `/` 切开后的数组）、`config.params`、`body` 判断，返回 `ok(data)` 或 `fail(提示)`。
2. 需要改数据时，在 `mock/state.js` 加函数，改完调用 `saveState()`；需要抛错时直接 `throw new Error('提示')`，`server.js` 会转成失败返回。
3. 需要新的初始数据字段时，在 `mock/data.js` 的 `createSeedState()` 返回值里加上。
4. 页面照旧通过 `src/api/` 下的模块调用，不要绕过 `client.js` 直接写请求。

## 如何修改初始数据

初始数据都在 `src/api/mock/data.js`：

| 内容 | 位置 | 现在有什么 |
| --- | --- | --- |
| 部署机器 | `MACHINES` | 3 台，编号 0 是主节点，容量 40 / 32 / 28，每台带 IPv4、IPv6、MAC 地址 |
| 卫星 | `buildSatellites()` | 3 个轨道面（A、B、C），每个轨道面 4 颗，共 12 颗 |
| 地面站 | `GROUND_STATIONS` | 4 个：北京、上海、西安、成都 |
| 网络节点 | `buildInstances()` | 12 颗卫星 + 4 个地面站，共 16 个；第 6、第 11 个默认停止，方便演示启停 |
| 链路 | `buildLinkDefinitions()` | 共 24 条：每个轨道面 4 条环内链路、6 条跨面链路、4 条星地链路、2 条地面有线链路 |
| 节点类型 | `TYPE_CONFIG` | Satellite、GroundStation、Gateway 三种，各带镜像与资源限额 |
| 文件目录 | `buildFiles()` | `config/`、`logs/`、`data/`、`images/`，含拓扑、运行配置、日志、CSV 等文本文件 |
| 数据库条目 | `buildDatabase()` | `/config/...`、`/topology/planes`、`/status/links/summary` 等，其中一条是纯文本，用来演示只读模式 |

改完这些数据，在概览页点“重置模拟环境”即可看到新内容；直接刷新页面看到的仍是 localStorage 里的旧数据。

## 与真实后端的差异与限制

- 没有真实容器和终端。节点终端、链路抓包终端都指向 `public/mock-terminal.html`，命令输出是写好的示例。
- 文件只在浏览器里。上传、删除、下载都操作虚拟目录，下载是把内容转成 data URL，不会写入真实服务器。
- 没有用户、权限和多用户。任何操作都不需要登录，也不区分角色。
- 数据只在本浏览器。换浏览器、换设备、清缓存都会丢失或回到初始数据。
- 不能与真实模拟环境交互。这里的拓扑、资源、日志都是演示数据。
- 数据库条目都是字符串。查看页会用 JSON 编辑器解析，非 JSON 的内容只能看不能改。

## 新增页面或接口后的验证

1. `npm run build` 能通过，没有编译错误。
2. `npm run dev` 打开页面，把新增页面或按钮实际点一遍，确认提示和列表都正常。
3. 打开浏览器开发者工具的 Network 面板，确认没有发往后端的 `/api` 请求；Console 没有报错。
4. 刷新页面，确认刚才的操作还在；再点“重置模拟环境”，确认恢复初始数据。
5. 涉及资源曲线时，等一个刷新周期（概览 8 秒、详情 5 秒）再核对数字。
6. 在 `change-logs/` 加一份记录。

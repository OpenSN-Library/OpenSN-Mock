# 项目结构

本文档说明 `ui-new` 的目录、页面、接口和开发方式。目录或路由有变化时请同步更新本文。

## 项目简介

OpenSN 网络仿真平台的前端重构版。旧前端在仓库的 `ui/` 目录，用 Create React App 搭建，保留不动；新前端的页面和旧版一一对应，用 Vite 重写。

技术栈：

| 名称 | 版本 | 用途 |
| --- | --- | --- |
| React | 18 | 页面框架，只写函数组件 |
| Vite | 5 | 开发服务器与打包，配合 `@vitejs/plugin-react` |
| react-router-dom | 6 | 路由 |
| antd | 5 | 界面组件库，配合 `@ant-design/icons` 图标、中文语言包 |
| axios | 1 | 请求库 |
| echarts | 5 | 图表，封装成 `EChart` 组件 |
| cesium | 1.115 | 三维地球库（浏览器里画三维场景） |
| resium | 1.17 | 把 Cesium 包成 React 组件 |
| vanilla-jsoneditor | 0.23 | JSON 查看与编辑，封装成 `JsonEditor` 组件 |
| vite-plugin-cesium | 1.2 | 打包时处理 Cesium 的静态资源 |

## 运行与构建

需要 Node.js 18 及以上。在 `ui-new/` 下执行：

| 命令 | 说明 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 开发服务器，地址 http://localhost:3100 |
| `npm run build` | 打包到 `build/` |
| `npm run preview` | 预览打包结果 |
| `make build` | 安装依赖并打包 |
| `make clean` | 删除 `build/` |

开发时 `/api` 由 Vite 代理到 `http://127.0.0.1:8080`，配置在 `vite.config.js`。别名 `@` 指向 `src`，导入写 `@/...`。

仓库根目录的 Makefile 目前仍构建旧 `ui/`。要打包本目录，直接在 `ui-new/` 下执行命令，或者把根 Makefile 里的 `cd ui` 改成 `cd ui-new`。

## 页面与路由

路由和页面在 `src/router/routes.jsx` 登记，菜单在 `src/router/menu.jsx` 登记。

| 路由 | 页面文件 | 标题 | 说明 |
| --- | --- | --- | --- |
| `/overview` | `src/pages/overview/Overview.jsx` | 概览 | 统计卡片、运行控制、节点类型、三维拓扑 |
| `/nodes/instances` | `src/pages/nodes/NodeList.jsx` | 网络节点列表 | 节点列表，可启动、停止、进详情 |
| `/nodes/machines` | `src/pages/nodes/MachineList.jsx` | 部署机器 | 物理机器列表 |
| `/nodes/instance/:nodeIndex/:instanceId` | `src/pages/nodes/NodeDetail.jsx` | 节点详情 | 不在菜单里，由列表页或三维视图打开 |
| `/links/list` | `src/pages/links/LinkList.jsx` | 链路列表 | 链路列表，可进详情 |
| `/links/link/:nodeIndex/:linkId` | `src/pages/links/LinkDetail.jsx` | 链路详情 | 不在菜单里，由列表页或三维视图打开 |
| `/files` | `src/pages/files/FileManager.jsx` | 文件管理 | 文件树、预览、上传、下载、删除 |
| `/database` | `src/pages/database/DatabaseViewer.jsx` | 数据库查看 | 键列表与 JSON 编辑 |
| `/help/manual` | `src/pages/help/HelpPage.jsx` | 帮助文档 | 中文使用说明 |
| `/help/about` | `src/pages/help/AboutPage.jsx` | 关于 | 项目信息 |

其他跳转：

- `/` → `/overview`
- `/nodes` → `/nodes/instances`
- `/links` → `/links/list`
- `/help` → `/help/manual`
- 其他路径显示 404 页面

详情页的用法：列表页调 `useOpenPage(path, title)` 打开，浏览器地址同步变化。详情页由路由传参：`NodeDetail({ nodeIndex, instanceId })`、`LinkDetail({ nodeIndex, linkId })`。

## 接口模块

接口文件都在 `src/api/`，统一从 `/api` 前缀发起。返回值是后端的 `{ code, msg, data }`，`code` 不为 0 时 `client.js` 会抛错，页面取数据用 `res.data`。

| 文件 | 负责的接口 | 使用页面 |
| --- | --- | --- |
| `client.js` | 创建 axios 实例，`baseURL` 为 `/api`，统一处理返回和错误 | 全部 |
| `emulation.js` | `/emulation/`：读配置、启动、停止、重置、上传拓扑、更新节点类型 | 概览 |
| `instance.js` | `/instance/`：网络节点列表、详情、启动、停止 | 网络节点列表、节点详情 |
| `node.js` | `/node/`：部署机器列表、机器详情 | 部署机器、概览统计 |
| `link.js` | `/link/`：链路列表、详情、删除；`/link_parameter/`：链路参数 | 链路列表、链路详情、概览 |
| `metrics.js` | `/resource/last/`、`/resource/period/`：节点、链路、实例的最新与历史资源 | 概览、节点详情、链路详情 |
| `position.js` | `/position/all`：节点经纬度位置 | 概览三维拓扑 |
| `file.js` | `/file/`：列表、预览、上传、删除、下载地址 | 文件管理 |
| `database.js` | `/database/`：条目列表、更新、删除 | 数据库查看 |
| `webshell.js` | `/webshell/`：实例终端、链路抓包终端 | 节点详情、链路详情 |

## 第三方组件说明

| 用途 | 用的库 | 说明 |
| --- | --- | --- |
| 三维拓扑 | Cesium + resium | Cesium 是浏览器里的三维地球库；resium 把它包成 React 组件，页面里直接写 `<Viewer>`、`<Entity>`。底图关闭在线影像，地球和背景设成深色，不设 Cesium ion（Cesium 官方的在线地图服务）的 token，不请求外部地图服务 |
| 图表 | ECharts 5 | 封装在 `src/components/common/EChart.jsx`，按需注册折线图、柱状图和常用组件；配色和折线图配置在 `src/utils/chart.js` |
| JSON 查看与编辑 | vanilla-jsoneditor | 封装在 `src/components/common/JsonEditor.jsx`，树形模式；`value` 变化时重新载入，编辑时通过 `onChange` 回传内容 |
| 树、表格、抽屉、标签、提示 | antd 5 | 直接用 antd 自带组件，没有另外引入树或表格库 |
| 图标 | @ant-design/icons | 没有用图标字体或 `react-icons` |

没有引入外部字体，字体用系统字体组合（`PingFang SC`、`Microsoft YaHei` 等），定义在 `src/styles/theme.css`。

## 与旧版 ui 的差异

| 项目 | 旧版 `ui/` | 新版 `ui-new/` |
| --- | --- | --- |
| 构建工具 | Create React App + craco | Vite 5 |
| 依赖 | 含 craco、craco-cesium、node polyfill、react-icons、react-monaco-editor、echarts-for-react | 只保留 Vite、React、antd、echarts、cesium、resium、vanilla-jsoneditor 等必要依赖 |
| 目录 | `Page/`、`Component/`、`Request/`、`Model/` 按文件类型平铺 | 按 `api`、`components`、`config`、`context`、`hooks`、`pages`、`router`、`styles`、`utils` 分层 |
| 布局 | 顶部横向菜单 | 侧边栏（一级、二级菜单）+ 顶栏 + 面包屑 + 标签页 + 内容区 |
| 标签页 | 没有 | 有，切换不卸载页面 |
| 详情页 | `window.open` 打开新浏览器标签，独立路由 | 在当前布局里新增标签页 |
| 详情页信息 | 字段按顺序平铺 | 按基本信息、资源监控、连接信息、终端等分成区块 |
| 三维底图 | Cesium 默认在线影像，需要 ion token | 深色地球，不依赖外部地图服务 |
| 图表 | `echarts-for-react` | 自己封装的 `EChart`，直接使用 ECharts |
| 终端 | 可编辑标签页管理多个终端窗口 | 终端放在详情页的卡片里，节点详情可开多个会话；抓包终端只保留一个窗口 |
| 运行配置器 | 有页面，内容是 iframe，地址来自 `GetCodeServerConfiguration` | 去掉，后端已删除该接口 |
| 未使用文件 | 空文件、`reportWebVitals.js`、只 import 未渲染的命名空间组件 | 不迁移 |
| 帮助与关于 | 一句占位文字 | 中文文档页 |
| 主题 | 只有暗色 | 明暗两种，可切换 |

## 新增一个页面的步骤

1. 建页面文件：在 `src/pages/` 下新建目录和 `.jsx` 文件，根节点用 `PageContainer` 包一层。
2. 登记路由：在 `src/router/routes.jsx` 的 `appRoutes` 里加一项 `{ path, element }`。带参数的路径把 `element` 写成函数，例如 `(params) => <Detail id={params.id} />`，标题用 `title: (params) => ...`。
3. 登记菜单：在 `src/router/menu.jsx` 的 `menuConfig` 里加一项，`key` 必须与路由 `path` 完全一致。菜单不放的页面（如详情页）跳过这步；如果详情页需要正确的面包屑，在 `DETAIL_ROUTES` 里加一条前缀和上级菜单。
4. 需要新接口时，在 `src/api/` 加模块，并在 `src/api/index.js` 导出。
5. 在 `change-logs/` 新增一份记录，说明背景、内容、涉及文件和验证方式。
6. 本地跑 `npm run build` 确认编译通过，再 `npm run dev` 实际点一遍页面。

## 开发注意事项

1. 页面在标签页内渲染。外层 `.tab-pane` 已经有内边距和纵向滚动，页面不要再自己加固定的高度或 `padding`；用 `PageContainer` 即可。
2. 切换标签页不会卸载页面，只是隐藏。页面里的定时器、表单数据都会保留；需要清理的东西写在 `useEffect` 的返回函数里，关闭标签页时才会执行。
3. 接口统一写在 `src/api/`，不要在页面里直接调 axios，也不要把后端地址写死。开发时用 Vite 代理，打包后前后端同源。
4. 颜色、圆角、字号用 `src/styles/theme.css` 里的 CSS 变量，例如 `var(--accent)`、`var(--foreground-muted)`、`var(--radius-md)`，不要写死颜色。图表颜色用 `CHART_COLORS`。
5. 操作提示用 `App.useApp()` 拿到的 `message`，不要用 antd 的静态 `message.xxx`。
6. 定时刷新用 `usePolling`，上一个请求结束才发下一个，避免请求堆积。
7. 导入统一用别名 `@/...`，不要写一长串相对路径。

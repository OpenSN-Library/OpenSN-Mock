# 变更记录

本目录记录 `ui-new` 的每次改动，便于以后查“什么时候改的、改了哪里、怎么验证”。

## 命名规则

文件名格式：`YYYY-MM-DD-简述.md`，日期是改动完成的日期，简述用两三句中文概括内容，不加空格。

示例：`2026-10-30-节点与链路页面.md`。

## 每份记录的写法

每份记录包含以下四部分：

| 部分 | 写什么 |
| --- | --- |
| 变更背景 | 为什么改，改之前是什么情况 |
| 变更内容 | 改了什么，分条写 |
| 涉及文件 | 新增、修改、删除的文件路径，按实际仓库路径写 |
| 验证方式 | 怎么确认改对了，一般写编译命令和实际访问的页面 |

有新改动时在本目录新建一份记录，再在下面的表格里加一行。不要修改历史记录的内容。

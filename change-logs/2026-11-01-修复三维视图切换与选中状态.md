# 2026-11-01 · 修复三维视图切换与选中状态

## 变更背景

概览页三维视图在初始化时关闭了 Cesium 自带的视图切换按钮，界面上看不到 3D/2D 切换入口。

另外，双击三维视图里的节点或链路后，Cesium 会保留“当前选中实体”和“相机跟踪实体”两个状态。页面原来没有清理这两个状态，所以双击之后看起来一直处于选中状态，也没有办法取消；双击后的相机还会跟着实体走。

## 变更内容

1. 恢复三维视图右上角的视图切换按钮。不再关闭 Cesium 的 `sceneModePicker`，可以在 3D、2D 和 Columbus View 之间切换。
2. 新增 `CesiumSelectionCleaner` 组件，在画布的单击和双击事件之后清除 `viewer.selectedEntity` 和 `viewer.trackedEntity`。双击打开详情标签页的行为不变，但不会再留下无法取消的选中状态。
3. 保留原来的 `infoBox`、`selectionIndicator` 关闭设置，三维视图里不出现 Cesium 默认的信息框和选中框。

## 涉及文件

- `src/pages/overview/components/TopologyViewer.jsx`：恢复视图切换按钮，新增点击后清理选中状态的组件。

## 验证方式

在演示版上实际验证（`npm run build` 后用浏览器访问）：

1. 三维视图右上角有视图切换按钮，能切到 2D 再切回 3D。
2. 双击三维视图里的节点，正常新增“节点详情”标签页；此时再点空白处或节点，没有残留的选中/跟踪状态，相机可以自由拖动。
3. 单击节点、双击空白处、双击链路的行为与上面一致。
4. 浏览器控制台没有报错。

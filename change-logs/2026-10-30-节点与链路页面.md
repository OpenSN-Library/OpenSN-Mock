# 2026-10-30 · 节点与链路页面

## 变更背景

旧版网络节点、部署机器、链路三个列表和两个详情页都在 `ui/src/Page/` 下，写法各不相同。

列表页的“查看详情”用 `window.open` 打开新浏览器标签，详情页是独立路由（`/instance/...`、`/link/...`），没有侧边栏、顶栏和标签页，看起来像另一个站点。详情页按旧的字段顺序平铺，信息没有分组。

新版把这些页面重写，统一放进当前布局。

## 变更内容

1. 网络节点列表（`/nodes/instances`）：显示节点 ID、名称、类型、部署机器、运行状态，带启动和停止操作。
2. 部署机器列表（`/nodes/machines`）：顶部三个统计卡片（机器总数、剩余可分配节点总数、主节点数量），下面表格显示机器编号、角色、剩余可分配节点数、IPv4、IPv6、MAC 地址。
3. 节点详情（`/nodes/instance/:nodeIndex/:instanceId`）重新分为四块：基本信息、资源监控、连接信息、远程终端。
4. 链路列表（`/links/list`）：显示链路 ID、类型、状态、两端节点、部署机器。
5. 链路详情（`/links/link/:nodeIndex/:linkId`）重新分为六块：基本信息、链路参数、两端信息、链路端地址信息、资源监控（吞吐量与数据包两组图）、抓包终端。
6. 详情页改为在当前布局里新增标签页打开，不再 `window.open`。列表页调用 `useOpenPage(path, title)`，浏览器地址同步变化，标签页标题带编号，例如“节点详情 · 实例名”。
7. 列表数据定时刷新，间隔沿用 `POLL_INTERVAL`（8 秒）；详情页的资源图表按 `DETAIL_POLL_INTERVAL`（5 秒）刷新。
8. 图表组件换了：去掉 `echarts-for-react`，改成自己封装的 `EChart`，直接使用 ECharts 5 的按需引入。时间范围共用 `RESOURCE_PERIODS` 里的 9 个选项。
9. 远程终端和抓包终端仍用 iframe 嵌入后端返回的 webshell 地址（`http://addr:port`）。节点详情里可以开多个终端会话，用可编辑标签页切换；链路详情的抓包终端只保留一个窗口，未启动时显示提示。

## 涉及文件

新增：

- `src/pages/nodes/NodeList.jsx`：网络节点列表。
- `src/pages/nodes/MachineList.jsx`：部署机器列表。
- `src/pages/nodes/NodeDetail.jsx`：节点详情。
- `src/pages/links/LinkList.jsx`：链路列表。
- `src/pages/links/LinkDetail.jsx`：链路详情。

复用既有文件：

- `src/components/common/EChart.jsx`：图表组件。
- `src/components/common/PageContainer.jsx`、`GlassCard.jsx`、`StatusTag.jsx`：页面容器、卡片、状态标签。
- `src/hooks/useOpenPage.js`、`src/hooks/usePolling.js`：打开标签页、定时刷新。
- `src/api/instance.js`、`src/api/node.js`、`src/api/link.js`、`src/api/metrics.js`、`src/api/webshell.js`：列表、详情、资源、终端接口。
- `src/config/constants.js`、`src/utils/format.js`、`src/utils/chart.js`：刷新间隔、数值格式化、图表配置。

## 验证方式

```bash
cd ui-new && npm install && npm run build
```

`npm run dev` 启动后检查：

1. 从侧边栏进入网络节点列表、部署机器、链路列表，数据正常显示。
2. 点击“查看详情”，在当前布局里新增标签页，地址栏同步变化，没有打开新浏览器窗口。
3. 节点详情的四块内容、链路详情的六块内容都有数据；切换时间范围后图表更新。
4. 启动终端按钮能拿到 webshell 地址，iframe 里能操作。
5. 关闭详情标签页后，列表标签页仍在，数据没有丢。

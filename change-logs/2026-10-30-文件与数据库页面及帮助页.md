# 2026-10-30 · 文件与数据库页面及帮助页

## 变更背景

旧版文件管理、数据库查看、帮助、关于四个页面都在 `ui/src/Page/` 下，是早期按接口返回结构直接拼出来的：布局用固定宽度的卡片，操作按钮散落在卡片里。

数据库页面有两个实际问题：提交时字段名和后来依赖的后端不一致；编辑器里的修改也没有传回页面。

帮助页和关于页只有一句“未完成”的占位文字。

另外旧版的运行配置器页面只是一个 iframe，地址来自 `GetCodeServerConfiguration` 接口，该接口后端已经删除。

## 变更内容

1. 文件管理（`/files`）重做，左右两栏：
   - 左栏是文件树，展开目录时才请求该层文件列表，不在进入页面时一次拉完。左栏顶部是上传和刷新按钮。
   - 右栏显示选中文件的文本预览，下面是下载、删除按钮。
   - 上传的文件放到当前选中的目录，预览只支持文本文件。
   - 下载靠临时 `<a>` 标签触发，地址由 `fileApi.downloadUrl` 生成，不经过请求库。
2. 数据库查看（`/database`）重做，左右两栏：
   - 左栏是树形键列表，键名按 `/` 分层，目录节点自动展开。
   - 右栏用 JSON 编辑器查看和修改选中的条目，下面是保存、删除按钮。
   - 修正提交字段：旧版提交 `{ key, value }`，后端读的是 `item` 字段；新版提交 `{ key, item }`。
   - 修正编辑器取值：旧版 `onChange` 是空函数，用户改了内容不会传回页面，保存时提交的是空值；新版把编辑器内容回传给页面，保存的是当前编辑结果。条目不是合法 JSON 时只允许查看文本，并给出提示。
3. 新增中文帮助文档页（`/help/manual`），按功能和页面分节，说明各页面能做什么、数据来自哪里。
4. 新增关于页（`/help/about`），写项目名称、用途、技术栈和目录入口。
5. 去掉运行配置器页面：新版没有该菜单和路由，也没有 iframe，不再调用 `GetCodeServerConfiguration`。旧 `ui/` 目录保留，里面的文件没有改动。

## 涉及文件

新增：

- `src/pages/files/FileManager.jsx`：文件管理。
- `src/pages/database/DatabaseViewer.jsx`：数据库查看。
- `src/pages/help/HelpPage.jsx`：帮助文档。
- `src/pages/help/AboutPage.jsx`：关于页。

复用既有文件：

- `src/components/common/JsonEditor.jsx`、`src/styles/json-editor.css`：JSON 查看与编辑。
- `src/api/file.js`、`src/api/database.js`：文件与数据库接口。
- `src/components/common/PageContainer.jsx`、`GlassCard.jsx`：页面容器与卡片。

不再使用的旧文件（保留在 `ui/`，新版不引用）：

- `ui/src/Page/TopologyConfiguratorPage.js`
- `ui/src/Request/platform.js`（只有 `GetCodeServerConfiguration` 一个接口）

## 验证方式

```bash
cd ui-new && npm install && npm run build
```

`npm run dev` 启动后检查：

1. 文件管理：展开目录能看到子文件；选中文本文件右侧出现内容；上传、下载、删除各有提示。
2. 数据库：点击树上的键，右侧加载对应 JSON；改一个值后保存，重新选中同一键能看到修改后的内容；删除后该键从树里消失。
3. 帮助文档和关于页能正常打开，内容不是占位文字。
4. 侧边栏里没有运行配置器入口，也没有对应的页面和 iframe。

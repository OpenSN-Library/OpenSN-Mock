# 2026-10-30 · 概览页与三维拓扑

## 变更背景

旧版概览页（`ui/src/Page/OverviewPage.js`）把运行状态、资源占用、节点类型和三维视图堆在几张卡片里，信息没有层次。

三维视图用 Cesium 默认配置，依赖 Cesium ion 的在线地图，需要在 `MainPage.js` 里写死 ion 访问 token，离线环境或 token 失效时底图就显示不出来。

双击立体视图里的节点会 `window.open` 打开新浏览器标签，脱离当前页面框架。

新版概览页把这些内容重新组织，并去掉外部地图依赖。

## 变更内容

1. 页面结构改为四块，从上到下依次是统计卡片、运行控制、节点类型配置、三维拓扑视图。
2. 统计卡片共 4 个：运行状态、部署机器数、网络节点数、链路数，数据和资源占用都来自后端接口。
3. 运行控制放在同一页里：启动模拟、停止模拟、重置模拟环境、上传拓扑配置、上传节点类型配置，另外显示 CPU 使用率、内存占用、交换内存占用三项汇总。上传的文件在前端读成 JSON 后直接提交给后端，不保存在浏览器里。
4. 节点类型配置用表格展示：类型名称、镜像、CPU 限额、内存限额。旧版在表格上方放了一个“添加节点类型”按钮，点了没有反应，新版去掉了。
5. 三维拓扑仍然用 Cesium（浏览器里的三维地球库），通过 resium 以 React 组件的方式渲染。
   - 底图改成深色地球：关闭在线底图，地球和背景都设成接近纯黑，不再设置 ion token。
   - 节点画成蓝色圆点并带名称标签；链路画成线段，颜色按吞吐量从绿到红变化。
   - 只在模拟运行中、且链路参数里 `connect` 为 1 时才画链路。
   - 没有位置数据时，视图上显示一句提示。
6. 双击三维视图里的节点或链路，在当前布局的标签页里打开对应详情页，不再打开新浏览器标签。
7. 数据每 8 秒刷新一次，间隔定义在 `src/config/constants.js` 的 `POLL_INTERVAL`。
8. 标签页切回概览时，通知 Cesium 重新计算画布大小；容器尺寸变化时也会重算。

## 涉及文件

修改 / 新增（均在 `ui-new/` 下）：

- `src/pages/overview/Overview.jsx`：页面主体，负责取数和定时刷新。
- `src/pages/overview/components/RuntimeControls.jsx`：运行控制、配置上传、资源汇总。
- `src/pages/overview/components/NodeTypePanel.jsx`：节点类型配置表格。
- `src/pages/overview/components/TopologyViewer.jsx`：Cesium 三维视图，节点与链路绘制。
- `src/api/emulation.js`、`src/api/node.js`、`src/api/instance.js`、`src/api/link.js`、`src/api/metrics.js`、`src/api/position.js`：页面用到的接口。
- `src/hooks/usePolling.js`：定时刷新。
- `src/utils/format.js`：内存、CPU、百分比格式化。
- `src/config/constants.js`：刷新间隔。
- `vite.config.js`：加 `vite-plugin-cesium`，打包时复制 Cesium 静态资源。

## 验证方式

```bash
cd ui-new && npm install && npm run build
```

`npm run dev` 启动后访问 http://localhost:3100/overview ，检查：

1. 4 个统计卡片的数字与后端返回一致，等待 8 秒后数字会更新。
2. 启动、停止、重置按钮操作后有提示，页面状态跟着变化。
3. 上传合法的拓扑配置和节点类型配置能成功；上传非 JSON 文件时提示失败。
4. 三维视图显示深色地球，节点和链路可见；拖动旋转、滚轮缩放正常。
5. 双击节点或链路，在标签页里打开详情，浏览器地址同步变化。
6. 浏览器断网时底图仍然显示，说明没有依赖外部地图服务。

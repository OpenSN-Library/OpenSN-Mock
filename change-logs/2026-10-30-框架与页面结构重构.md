# 2026-10-30 · 框架与页面结构重构

## 变更背景

旧前端 `ui/` 用 Create React App 加 craco 搭建：构建慢，配置分散在 `craco.config.js` 和 `src/webpack.config.js`；目录按文件类型平铺，没有分层；布局是顶部横向菜单，切换页面会整页重绘。

因此新建 `ui-new/`，重写入口、目录、布局与路由。旧 `ui/` 保留不动。

## 变更内容

1. 构建工具换成 Vite 5。入口是 `index.html` + `src/main.jsx`；别名 `@` 指向 `src`；打包产物在 `build/`；Cesium 交给 `vite-plugin-cesium`，不再用 `craco-cesium` 和多个 node polyfill。
2. 新建 `src/` 分层目录：`api`、`components`（下分 `common`、`layout`）、`config`、`context`、`hooks`、`pages`、`router`、`styles`、`utils`。页面按功能放进 `pages/` 下的子目录。
3. 布局改为侧边栏（一级、二级菜单，可收起）+ 顶栏（折叠按钮、当前页面标题、明暗切换）+ 面包屑 + 标签页 + 内容区。顶栏不放用户信息，后端没有用户体系。
4. 支持明暗两种主题。`ThemeContext` 记录当前主题并写入浏览器本地存储；主题值挂在 `document.documentElement` 的 `data-theme` 上，`theme.css` 里两套变量；默认暗色。
5. 路由与菜单分开登记。`routes.jsx` 管路径和页面，`menu.jsx` 管菜单、标题、面包屑和选中项。详情页不进菜单，由列表页打开。
6. 标签页机制。`TabsContext` 记录已打开的页面；切换标签页只隐藏其他页面，不卸载，页面状态保留；关闭标签页才卸载。
7. 不再迁移的旧内容：
   - `CreateInstanceForm.js`、`CreateLinkForm.js`、`NamespaceLinkDrawer.js` 是空文件。
   - 命名空间相关组件（`CreateNamespaceForm.js`、`GetNamespaceList.js` 等）在 `MainPage.js` 里只 import 了、没渲染，实际未使用。
   - `reportWebVitals.js` 是模板自带；`react-icons` 只画一个图标，改用 `@ant-design/icons`；`react-monaco-editor` 只写在依赖里、代码没引用；`echarts-for-react` 换成自己封装的 `EChart`。

## 涉及文件

新增文件（均在 `ui-new/` 下）：

- 根目录：`index.html`、`vite.config.js`、`package.json`、`Makefile`
- 入口与路由：`src/main.jsx`、`src/App.jsx`、`src/router/index.jsx`、`src/router/routes.jsx`、`src/router/menu.jsx`
- 布局：`src/components/layout/AppLayout.jsx`、`Sidebar.jsx`、`Header.jsx`、`Breadcrumbs.jsx`、`TabBar.jsx`、`ThemeToggle.jsx`
- 状态与配置：`src/context/ThemeContext.jsx`、`TabsContext.jsx`、`DrawerContext.jsx`、`src/config/appConfig.js`、`src/config/constants.js`
- 样式与通用：`src/styles/theme.css`、`src/styles/layout.css`、`src/components/common/DrawerHost.jsx`、`src/hooks/useOpenPage.js`、`src/hooks/usePolling.js`、`src/pages/NotFound.jsx`

## 验证方式

```bash
cd ui-new && npm install && npm run build
```

启动开发服务器：`npm run dev`，访问 http://localhost:3100 ，检查：

1. `/` 自动跳到 `/overview`，未知路径显示 404 页面。
2. 侧边栏一级菜单能展开，点击二级菜单后标签页新增一项。
3. 切换标签页内容保留，关闭标签页回到相邻页。
4. 顶栏开关能切换明暗主题，刷新后主题不变。

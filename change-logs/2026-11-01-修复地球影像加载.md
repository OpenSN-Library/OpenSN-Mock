# 2026-11-01 · 修复地球影像加载

## 变更背景

三维视图初始化时关闭了 Cesium 的在线底图，只给地球设置了深色底色。这样在没有配置 Cesium ion 的情况下，地球表面没有影像，只显示成一个黑色球体，看起来像背景没有加载。

## 变更内容

1. 使用 Cesium 自带的 NaturalEarthII 本地影像作为地球表面。影像文件在 Cesium 的静态资源目录里，不请求在线地图服务，也不需要配置 Cesium ion token。
2. 在三维视图里通过 `TileMapServiceImageryProvider` 加载影像，再用 `ImageryLayer` 添加到场景；没有影像时仍然回退到深色地球，不影响页面其他功能。
3. 打开地球的大气效果，地球边缘有一圈柔和的光晕，和深色背景过渡更自然。
4. 演示版放在 GitHub Pages 时使用同一套本地影像，不依赖外部服务。

## 涉及文件

- `src/pages/overview/components/TopologyViewer.jsx`：加载本地地球影像、打开大气效果。
- `docs/项目结构.md`、`docs/GitHub Pages 部署.md`：更新三维底图说明。

## 验证方式

在演示版构建产物上实际验证（`npm run build`，再把 `build/` 放到子路径下访问）：

1. 三维视图中能看到带大陆和海洋的地球，不再是一个黑色球体。
2. 浏览器网络面板里能看到 NaturalEarthII 的瓦片请求，状态为 200；没有请求在线地图服务。
3. 3D/2D 切换、双击节点打开详情、点击后取消选中都正常。
4. 控制台没有报错。
